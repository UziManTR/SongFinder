# SongFinder 🎧

**A dating app, but for music.** Like tracks you love, pass on tracks you don't, and build a ranked playlist from your taste.

## Features
- Animated, responsive dark interface
- Like / dislike / skip controls, plus keyboard shortcuts
- Live liked, passed, and match-rate stats
- Playlist size selector from 10 to 50 tracks
- Ranked matches and playlist export as a text file
- Sample tracks included so the prototype works immediately

## Run it
Open `index.html` in a browser, or enable GitHub Pages in **Settings → Pages** and deploy from the `main` branch root.

## YouTube Music integration
Directly creating a playlist in a user's YouTube Music account is not enabled in this front-end prototype. It needs a secure Google OAuth flow and a supported API/backend integration. Never put OAuth client secrets or tokens in public frontend code.

## Current scope
This is a polished interactive prototype with a sample catalog. Live song discovery, real recommendation ranking, and one-click YouTube Music playlist creation are the next integration steps.
